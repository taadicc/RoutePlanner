# Route Planning Application

A Java desktop application developed as part of the Programming Languages 2 course.

The project focuses on route planning and transportation network visualization using GraphStream.

## Technologies

- Java
- GraphStream

## Overview

The application explores graph-based approaches to representing transportation networks and working with routes between cities.

## Project Purpose

This project was developed to practice object-oriented programming, graph representation, and Java application development.
